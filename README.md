📱 Phone Price Analytics

A data-driven exploratory analysis project aimed at understanding the key factors influencing smartphone prices. Using Python, Pandas, Matplotlib, and Seaborn, this project uncovers insights into how features like RAM, battery, CPU, and camera specifications affect market pricing.

🚀 Project Overview

Smartphone pricing is influenced by various hardware and software specifications. This project analyzes a dataset (Cellphone.csv) to:

Explore relationships between phone specifications and price.

Identify the most impactful features.

Visualize patterns in the dataset.

Derive actionable insights that can help in market analysis.

🛠️ Tech Stack

Python

Pandas – Data manipulation

Matplotlib & Seaborn – Visualization

NumPy – Numerical operations

📂 Dataset

The dataset (Cellphone.csv) contains smartphone details with features like:

Price – Selling price of the phone

Sale – Sales figures

Weight, Resolution, ppi

CPU Core, CPU Frequency

Internal Memory, RAM

Rear Camera, Front Camera

Battery capacity

Thickness

📊 Analysis Performed

Data Cleaning & Preprocessing

Removed duplicates and missing values.

Extracted relevant columns for analysis.

Exploratory Data Analysis (EDA)

Statistical summaries of features.

Correlation heatmap of all numerical variables.

Visual exploration of feature vs. price.

Visualizations

Heatmap of feature correlations.

Scatter plots of Price vs RAM, Battery, Thickness, Camera specs.

Identified the highest and lowest priced products.

🔎 Key Insights

RAM shows the strongest positive correlation with smartphone price. High-RAM devices tend to be more expensive.

Battery capacity has a moderate influence, but ultra-high capacity alone doesn’t guarantee a higher price.

Front & Rear Camera quality moderately affect pricing — premium devices generally have stronger camera specs.

Thickness shows a weak or negative correlation — slim phones are often priced higher, but the impact isn’t strong.

CPU frequency and internal memory also contribute positively but not as strongly as RAM.
